# Welcome to AI Live and Labs Zurich 2026 Data Forge

Welcome, Hackathon Participants! This repository hosts the source code, configurations, and comprehensive step-by-step user guides for the **AI Live and Labs Zurich 2026 Data Forge** - *Your custom data cloud experience, built by you.* 

During this session, you will build advanced AI-powered database integrations, transactional bridges, and fullstack semantic search applications using state-of-the-art Google Cloud database features.

---

## 🚀 Deployed Lab Tracks

Here are the active lab tracks provisioned for your sandbox environment:

### 1. [Lab 1: From Data to Agent (BigQuery & Knowledge Catalog)](labs/lab01_bigquery_agentic_data_cloud/user_guide.md)
Build a governed AI agent on BigQuery with Knowledge Catalog grounding, BigQuery Graph, column-level security, and ADK.

### 2. [Lab 2: Agentic Data Cloud: Zero-ETL Federation (AlloyDB, Spanner & BigQuery)](labs/lab02_agentic_data_cloud_zero_etl/user_guide.md)
Move the same data into three engines with EXPORT DATA, federate it back into one BigQuery view, put two property graphs over it, and route every question to the one agent whose identity permits the answer.

### 3. [Lab 3: Publish ADK Agents to Gemini Enterprise (Labs 10 & 11)](labs/lab03_gemini_enterprise_agents/user_guide.md)
One click puts the governed Lab 10 analyst and the Lab 11 zero-ETL dispatch agent in front of business users: trial licence, Gemini Enterprise app, least-privilege A2A registration and the link to hand out.
